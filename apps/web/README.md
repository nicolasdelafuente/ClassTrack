# ClassTrack Web

React + Vite + TypeScript. Pantalla principal: **tablero de grupos** (CT-011).

## Dev

Desde la raíz del monorepo (con API + seed corriendo):

```bash
npm run seed
npm run dev:api
npm run dev:web
```

Abrí http://localhost:5173

Opcional: `VITE_API_URL` (default `http://localhost:3001/api`).
