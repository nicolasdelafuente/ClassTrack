# Usuarios

## v1 — quién usa ClassTrack

### Docente (único rol del MVP)

Persona que dicta *Desarrollo de Aplicaciones* / PPS junto a otros profesores.

**Quiere:**

- ver rápido cómo van todos los grupos del cuatrimestre
- abrir un grupo y ver integrantes, tema, docente a cargo y estado de sprints
- cargar asistencia / participación en el encuentro (celular)
- dejar de depender del Excel compartido para el día a día

**Contexto de uso:**

- en el aula o reunión semanal, casi siempre desde el celular
- en casa o escritorio, para planificar y revisar la cursada

**No necesita en v1:**

- vista de alumno
- login complejo con muchos roles (puede haber un acceso docente simple)
- sync automática con GitHub / Trello / Drive

---

## Más adelante (fuera del MVP)

| Rol | Idea |
|-----|------|
| Alumno / integrante de grupo | Ver su grupo, links, semáforo, feedback |
| Coordinación / admin de cursada | Alta de cuatrimestre, importar padrones, asignar docentes |

Estos roles se documentan cuando abramos esa etapa.
